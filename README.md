# Yasin Talha Gençsoy · Ghostkiller

Yazılım geliştirici, içerik üreticisi ve Ekransız Oyuncular'ın kurucu ortağıyım. Teknolojiyi ekran okuyucu kullanıcıları için erişilebilir kılan web ve masaüstü uygulamaları geliştiriyorum; ses işleme ve otomasyonla ilgileniyorum.

I'm a software developer, content creator, and co-founder of Ekransız Oyuncular. I develop accessible web and desktop applications for screen-reader users, with an interest in audio processing and automation.

[Web sitemiz / Our website](https://ekransizoyuncular.gen.tr/) · [Biyografim / About me](https://ekransizoyuncular.gen.tr/Yasin_Talha_Gencsoy.html)

## Çalışma alanlarım / My work

- Python, PHP ve SQL ile uygulama geliştirme / Application development with Python, PHP, and SQL
- Erişilebilir WordPress eklentileri ve klavye odaklı arayüzler / Accessible WordPress plugins and keyboard-driven interfaces
- NVDA eklentilerine katkı ve Türkçe yerelleştirme / NVDA add-on contributions and Turkish localization
- Ses işleme, miksaj ve ses tasarımı / Audio processing, mixing, and sound design
